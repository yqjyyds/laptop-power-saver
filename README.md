# laptop-power-saver
基于winform开发的笔记本省电工具，基于电源状态自动调整独立显卡和显示器这两个耗电大户的状态。使用电池时自动禁用独显和降低显示器规格，来帮助提升你笔记本电脑的续航。
主要功能：
1：通过Windows计划启动实现无感自启动，无需uac确认
2：首次启动需要配置省电策略，设置禁用gpu、调整显示器规格。强制测试后才能够保存配置文件，如果配置错误导致黑屏自动恢复默认
3：检测到电脑切换为电池时自动右下角弹窗确认是否切换为省电模式，倒计时内点击取消可忽略此次切换。倒计时超时或者点击确认时自动切换省电模式。
4：离电关机后再插电开机可询问是否关闭省电模式
